# 🚲 Travel Weather Planner

A simple Python program that checks whether a commute is feasible based on distance, weather, and available vehicles.

Built for the **freeCodeCamp Python Certification** curriculum.

---

## 📌 Logic Rules

* **0 miles:** Invalid (`False`).
* **$\le$ 1 mile:** Walkable if it is not raining.
* **1 – 6 miles:** Requires a bike and dry weather.
* **> 6 miles:** Requires a car or ride-share app.
